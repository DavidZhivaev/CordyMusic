# CordyMusic

**CordyMusic** — Discord-бот для прослушивания музыки в голосовых каналах. Бот позволяет удобно управлять музыкой и предлагает широкий набор функций для полноценного музыкального опыта.

---

## Возможности

- Поддержка популярных платформ: Yandex Music, Spotify, SoundCloud
- Управление очередью воспроизведения: просмотр, перемешивание, редактирование
- Музыкальные фильтры для улучшения звучания
- Удобное интерактивное меню поиска и воспроизведения треков
- Настройка ролей диджея для управления правами участников
- Слэш команды в современном стиле + команды с префиксом
